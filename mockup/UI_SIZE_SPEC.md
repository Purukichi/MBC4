# UI サイズ仕様（MBC4 1.1.0 準拠）

別プラグインの UI を MBC4 と同系統に見せるための**寸法の規則**です。色・質感・文字の選び方は [DESIGN_CONCEPT.md](DESIGN_CONCEPT.md) を参照してください。ここでは「どの大きさで、どの間隔で置くか」だけを決めます。

数値はすべて**ベース座標（100 % 表示時の論理 px）**です。実装の出典は `Source/UI/Grid.h` ほか。

---

## 1. ウィンドウとスケーリング

| 項目 | 値 | 備考 |
|---|---|---|
| ベースサイズ | 1240 × 800 | MBC4 の場合。別プラグインは幅・高さとも **10 の倍数**で自由に決める |
| 縦横比 | 固定 | ベースサイズの比率をそのまま保つ |
| 最小スケール | 1.0（= 1240 × 800） | |
| 最大スケール | 1.8（= 2232 × 1440） | |
| 初期スケール | **1.5**（= 1860 × 1200） | 初回起動時。以後は閉じたときのスケールを保存・復元（state の `uiScale`） |
| 拡大方法 | UI 全体をベース座標で描き、`AffineTransform::scale` で一括拡大 | 部品ごとにレイアウトし直さない |

**サイズ感をそろえる要点**: 別プラグインでも「ベース座標で設計 → 初期 1.5 倍」を守ると、文字・セル・余白の見かけの大きさが MBC4 と一致します。ウィンドウ全体の大きさが違っても、部品の大きさは同じに見えます。

## 2. グリッド

| 項目 | 値 |
|---|---|
| モジュール | 10 px（区画の境界、グラフの端、列の幅はすべて 10 の倍数） |
| セル | 3 × 3 px の正方形 |
| セルピッチ | 4 px（隙間 1 px） |
| セル列の横幅（2 列） | 7 px（3 + 1 + 3）。中心 `cx` に対して `cx - 3.5` から置く |

### セルのピクセル吸着

セルとその隙間は、どのスケールでも**整数のデバイスピクセル**に丸める（`Draw::Lattice`）。

- ピッチ = `round(4 × k)`、隙間 = `max(1, round(1 × k))`、セル = ピッチ − 隙間（`k` = 物理ピクセル倍率）
- 原点も 1 回だけデバイスピクセルに丸め、以後は整数ピッチで並べる
- このため、ある長さに入るセル数はスケールによって ±1 変わることがある（`fit()` で数える）

## 5. 文字

`Draw::text` の y は**文字の中心線**。サイズは JUCE の `FontOptions::withPointHeight`（ベース座標の値）。

| 役割 | 書体 | サイズ | 字間 | 主な使いどころ |
|---|---|---|---|---|
| label | Chivo Mono Regular | 8 | 0.8 px | 区画名、フェーダー名、ボタン |
| value | Chivo Mono Light | 9 | 0 | 数値 + 単位 |
| note | Chivo Mono Light | 7.5 | 0.6 px | 区画番号、バージョン |
| tick | Chivo Mono Light | 7.5 | 0 | 目盛りの数字 |

- ポップアップメニュー: Chivo Mono Light 13
- ツールチップ本文（日本語）: 10.5、見出し: label と同じ 8 / 字間 0.8（どちらも UI スケールを掛ける）

## 6. 部品の寸法

### 縦フェーダー（`CellFader` vertical）

| 項目 | 値 |
|---|---|
| 部品の矩形 | 44 × 202（描画幅 44 / クリック判定幅 28、中心 ±14） |
| 中心 x | 部品左端 +22 |
| 名前（label） | 中心 y +7 |
| セル | 上端 y +22、**2 列 × 40 段**（高さ 159 px ≒ 40 × 4） |
| 値（value） | 中心 y +194、値の編集欄 = 部品幅 × 14 px |
| つまみ | 値の段の 2 セルを `ink` で塗り、横の針を通す。針の長さ 18 px（中心 ±9）、太さ 0.5（ドラッグ中 1.0） |
| 並べる間隔 | 中心間 36 px（詰める場合）／ 45 px（ゆったり） |
| ドラッグ量 | 全域 160 px、Fine 時 ×0.2 |

MBC4 の配置（ウィンドウ y）: 部品上端 418、名前 425、セル上端 440、値 612。同じ行のフェーダーは**この 4 つの y をそろえる**。メーター（GR など）を並べるときも同じ y にする。

### グラフ

| 項目 | 値（MBC4） |
|---|---|
| 描画域 | x 150 – 1050、y 80 – 340（900 × 260）= **225 × 65 セル** |
| 区画の端からの余白 | 左 10、右 50（dB 目盛り用）、上 60（見出し + バンド名）、下 40（周波数ラベル） |
| dB 目盛り | 描画域の右 7 px、12 dB ごと、数字のみ（tick 書体、`ink2`） |
| 周波数ラベル | 中心 y 352、数字のみ（50 / 100 / … / 10k） |
| 基準線・境界線 | 0.5、ホバー・ドラッグ中 1.2 |
| 描画域上のラベル | 描画域上端から 10 px 上 |

### メーター

| 項目 | 値 |
|---|---|
| ドット | グラフと同じセル（3 px / 4 px ピッチ）、2 列 |
| 縦の範囲 | グラフ描画域と同じ y（上端・下端・dB 目盛りを共有） |
| 0 dB 線 | ドット 2 列の幅ちょうど（7 px）、太さ 0.5 |
| ピーク値 | ドット数字、上端 y 352（グラフの周波数ラベルと同じ行） |

### ドット数字・ロゴ

| 項目 | ドット | ピッチ | 1 文字 | 文字間 |
|---|---|---|---|---|
| ドット数字 | 1.6 px | 2 px | 5 × 7（高さ 13.6 px） | 1 列空ける |
| ロゴ | 3 px（セル） | 4 px | 4 × 5（高さ 19 px） | 1 列空ける。MBC4 は 4 文字で幅 75 px、左上 (30, 25.5) |

### 吹き出し・ツールチップ

| 項目 | 値 |
|---|---|
| 吹き出し | 高さ 14、幅 = 文字幅（value）+ 10、角丸 3、対象の 12 – 14 px 上に表示、描画域の左右にはみ出さない |
| ツールチップ | 余白 左右 9 / 上下 7、最大幅 220、角丸 3、カーソルから 14 px 離す、0.5 秒で表示（すべて UI スケールを掛ける） |
| リサイズ角 | 3 段の階段状セル（3 px / 4 px ピッチ）、右下から 2 px 内側 |

## 7. 線の太さ

| 種類 | 値 |
|---|---|
| 罫線 | 0.2 px（そのまま描く） |
| 基準線・針・境界線 | 0.5、操作中 1.0 – 1.2 |
| 枠線（トグル、選択セグメント） | 1 デバイス px |

0.2 px の罫線以外は、**1 デバイスピクセル未満にしない**（`Px::dev`）。位置もデバイスピクセルに吸着させる。
