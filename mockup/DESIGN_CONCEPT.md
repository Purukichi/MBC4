# プラグイン UI デザインコンセプト（PC1 スタイル）

自作プラグインの UI が、**機能にかかわらず必ず守る**見た目・寸法・手触りの規則です。どんな機能・パラメータ・レイアウトのプラグインにもそのまま当てはめられることだけを書いています。

数値はすべて**ベース座標（100 % 表示のときの論理 px）**です。

---

## 進め方

- 実装の前に、HTML 1 ファイル（`<canvas>` 描画）でモックアップを作り、見た目の承認を得てから移植する。数値はモックとコードで同じにする。
- 移植後は実機のスクリーンショットを撮り、モックと見比べる。
- 迷ったら「線を細く、色を減らし、四角で表し、余計な表示を足さない」を優先する。

---

## 1. 原則

**「グリッドに整列した、無彩色の計測器」**

1. **グリッド**: すべてを 10 px のモジュールに乗せる。区画の境界や表示域の端は 10 の倍数にそろえる。並んだ要素は上端・高さ・ベースラインをそろえる。
2. **背景は 1 色**: 区画を色で塗り分けない。区画は細い罫線だけで分ける。テーマはライトとダークの 2 つで、どちらも色の役割は同じにする。
3. **点はすべて四角**: 丸は使わない。表示・つまみ・数字・ロゴまで、正方形のセルで組む。表示域の空きセルも薄く描き、目盛りの代わりにする。操作用のアイコンだけは、文字と同じ大きさの線のアイコンにする。
4. **アクセントは 1 色**: 信号オレンジだけ。使うのは「効いている・変わった・オンになっている・基準を超えた」箇所と、ロゴの最後の 1 文字に限る。赤・緑・青は使わない。
5. **量はグレーの階調**: データの濃淡はグレーで表す。オレンジを濃淡に混ぜない。
6. **線は極細**: 罫線は 0.2 px。基準線も細く引くが、画面の 1 ピクセル未満にはしない。
7. **装飾をしない**: 目盛り線、トンボ、影、グラデーション、立体表現は使わない。目盛りは数字だけ。
8. **情報を絞る**: 常に見る必要のない情報は置かない。説明はツールチップに任せ、日本語はツールチップ本文だけに使う。

## 2. 色

- ライト: `#C7C8C3`、`#B9BAB5`、`#A6A7A2`、`#8F908B`、`#5C5D59`、`#2A2B29`
- ダーク: `#3A3B38`、`#4A4B47`、`#5E5F5B`、`#797A75`、`#A9AAA5`、`#D6D7D2`（強いほど明るい）

### コントラストの決まり

- 読ませる文字は `ink`・`ink2`・`ink3` のどれかにする。下限は `ink3`。それより薄い文字は**無効状態を示すときだけ**使う（`dText`）。
- 吹き出しは `ink` の地に `onInk` の文字（ライトでは黒地に明るい文字、ダークでは明るい地に暗い文字）。ツールチップは `tipBg` の地に `tipText` の本文、見出しは `accent`。
- 背景と見分けにくい色（`off`・`ghost`・`accentSoft`）は面やセルにだけ使い、文字や線には使わない。
- 新しい色を足すときは、両方のテーマの値を決め、背景とのコントラストが同じ段階になるようにする。

## 3. 文字

- 等幅フォント 1 種類: **Chivo Mono**（SIL OFL）。選んだ理由は、**0 の中に点や斜線がない**こと。Light と Regular を埋め込み、ライセンス（OFL.txt）を同梱する。
- 日本語（ツールチップの本文）は OS 標準のゴシック体を使う（Yu Gothic UI → Meiryo → ヒラギノ の順）。
- 字形を太らせない（線形のカバレッジで描く。egui では `AlphaFromCoverage::Linear`）。
- サイズは次の 4 段だけ。大きな文字が要るときはドット数字やドット文字で組む。

| 役割 | ウェイト | サイズ | 字間 | 表記 | 用途 |
|---|---|---|---|---|---|
| label | Regular | 8 | 0.8 | 大文字 | 区画名、部品名、ボタン |
| value | Light | 9 | 0 | 単位は `dB` `Hz` `%` | 数値、吹き出し、入力欄 |
| note | Light | 7.5 | 0.6 | 大文字 | 区画番号、バージョン、フッターのボタン |
| tick | Light | 7.5 | 0 | — | 目盛り |

- 例外は 2 つだけ: ポップアップメニューは Light 13、ツールチップは見出しが label と同じ 8 / 字間 0.8、本文（日本語）が 10.5。
- 位置の y は**文字の中心線**で指定する。中央揃えや右揃えは、末尾の字間を除いた**インクの幅**でそろえる。
- 値の書き方: 正負がある値には `+` を付ける。単位と数値の間は半角スペース（`0 dB`、`94 Hz`）。1000 以上の周波数は `k` で縮める（`1.20kHz`）。範囲の端は `OFF` のような言葉にしてよい。

## 4. ウィンドウとスケーリング

| 項目 | 値 | 備考 |
|---|---|---|
| ベースサイズ | 幅・高さとも **10 の倍数** | 中身に合わせて決める |
| 縦横比 | 固定 | ベースサイズの比率をそのまま保つ |
| スケール範囲 | **0.75 – 1.25** | リサイズ角のドラッグで連続して調整する |
| プリセット | **75 / 100 / 125 %** | フッター右端のボタン |
| 初期スケール | **1.0** | 初回だけ。以後は閉じたときのサイズを state に保存して復元する |
| ホストへの下限 | 0.5 | ホストが小さい窓を押しつけたときは UI 全体を縮めて収める（はみ出させない） |
| 拡大方法 | UI 全体をベース座標で描き、一括で拡大する | 部品ごとにレイアウトし直さない |

- **部品の大きさをそろえる**: 「ベース座標で設計し、初期 1.0 倍」を守る。そうすれば、ウィンドウ全体の大きさが違っても、文字・セル・余白の見かけの大きさがプラグイン同士でそろう。
- **画面に収める**: 100 % の窓は、FHD（1920 × 1080）・Windows 表示スケール 125 % の画面で、ホストのタイトルバーを含めてもタスクバーにかからない大きさにする。目安は高さ 740 以下。

## 5. グリッドとセル

| 項目 | 値 |
|---|---|
| モジュール | 10 px（区画の境界、表示域の端、列の幅はすべて 10 の倍数） |
| セル | 3 × 3 px の正方形。すべての表示の最小単位 |
| セルピッチ | 4 px（すき間 1 px） |
| セル列の横幅（2 列） | 7 px（3 + 1 + 3）。中心 `cx` に対して `cx - 3.5` から置く |

セルとそのすき間は、どのスケールでも**整数のデバイスピクセル**に丸め、どの拡大率でも同じ大きさに見えるようにする。

- ピッチ = `round(4 × k)`、すき間 = `max(1, round(1 × k))`、セル = ピッチ − すき間（`k` = 物理ピクセル倍率）
- 原点も 1 回だけデバイスピクセルに丸め、以後は整数ピッチで並べる
- このため、ある長さに入るセル数はスケールによって ±1 変わることがある。セル数は毎回数え直す

## 6. 外枠と区画

| 項目 | 値 |
|---|---|
| 外側の余白（上・左・右） | 20 px |
| フッター帯 | 下端の 40 px |
| サイド列（作る場合） | 120 px 幅 |
| ロゴ区画 | 高さ 30 px。ロゴ以外は置かない |
| 区画の境界 | 罫線だけで示し、塗り分けない |

中央の区画の大きさや並びは、プラグインに合わせて決めてよい。

### 区画の見出し

左上に小さな番号と名前を置く（例 `01 INPUT`）。番号は信号の流れの順番。

| 項目 | 値 |
|---|---|
| 位置 | 区画の左上から **x +10、中心 y +15** |
| 番号 | note 書体、`ink3`、例 `01` |
| 名前 | 番号の 14 px 右、label 書体、大文字 |
| 右上に置く部品（ボタン類） | 上端 y +7、高さ 16 px、右端は区画の右端から 10 px 内側 |

### フッター（システムバー）

機能に関係しない操作は、すべてフッターに同じ並びで置く。どのプラグインでも位置と順番を変えない。

```
V1.0.0 ……………………………………… ↺ ◧   75 100 125 ▟
バージョン                     リセット テーマ  UI サイズ  リサイズ角
```

| 項目 | 値 |
|---|---|
| 並び | 左端にバージョン表記。右端から順に UI サイズのボタン → 10 px 空けてテーマ切替 → すぐ隣に Reset |
| ボタンの幅 | どのボタンも「中身の幅 + 6 px」（文字なら文字幅、アイコンなら 7.5 px）。高さ 14 px（当たり判定）。同じグループのボタンはすき間なく並べる |
| 中心 y | 文字もアイコンも、すべてフッター上端 +11 |
| バージョン表記 | `V1.0.0` の形。x 20、note 書体、`ink3` |
| UI サイズのボタン | `75` `100` `125`、note 書体。最後のボタンの右端を外枠の右端にそろえる |
| Reset | アイコン（↺）。すべてのつまみとクロスオーバーなどを初期値に戻す |
| テーマ切替 | アイコン（◧）。ライトとダークを切り替える |
| 色 | 通常は `ink3`、ホバー中と「今の値」は `ink`。UI サイズがどのプリセットとも違うときは、どれも `ink` にしない |
| リサイズ角 | 3 × 3 px のセルを 4 px ピッチで 3 段の階段にし、ウィンドウ右下の隅に置く（`ink3`） |

- Undo・Redo のボタンは置かない。元に戻す・やり直しはキーボード（Ctrl+Z など）だけで行う。
- 区画の右上など、フッター以外に Reset やテーマ切替を置かない。

## 7. 部品

### つまみ（ノブ）

縦フェーダー・横スライダー・メーターに重ねたゲインなど、**値を動かす部品のつまみはすべて同じ形**にする。丸いノブ、ブロック状のつまみ、影や立体表現は使わない。

**形: 値の位置のセルを黒くするだけ。** セル以外のもの（針・線・枠）は描かない。

```
縦フェーダー            横スライダー
  ▫▫
  ▫▫               ▪▪▪▪▪▪▪▪█▫▫▫▫▫▫
  ██  ← 値の段              ↑ 値のセル
  ▪▪
  ▪▪  ← 点灯（基準値〜値）
```

| 項目 | 縦フェーダー | 横スライダー |
|---|---|---|
| 黒くするセル | 値の段の 2 セル（列すべて） | 値の位置の 1 セル |

- **黒い線（針）は付けない**: つまみを横切る線や、セル列からはみ出す線は描かない。値の位置は黒いセルだけで分かるようにする。
- **色**: 通常は `ink`、無効状態は `dKnob`。オレンジや `accentSoft` をつまみに使わない（点灯セルの色は基準値から値までの範囲だけに使い、つまみの段は必ず `ink` で上書きする）。
- **位置はセル単位**: 値は最も近いセルの段に丸めて表示する。セルの間に止めたり、滑らかに動かしたりしない。
- **状態で形を変えない**: ホバー中もドラッグ中も、つまみの形と色は同じ。操作できることはカーソルの形で示す。
- **メーターに重ねる場合**: メーターのセルの上に、同じ形のつまみ（黒いセル）を重ねる。メーターの基準レベルの線（0 dB など）はドット列の幅ちょうど 7 px の線で示す。
- 値の文字はつまみに付いて動かさず、部品の決まった位置（縦フェーダーなら下）に置く。

### 縦フェーダー

2 列のセルの柱。基準値から現在値までのセルを点灯する（正負がある値は中央から、ない値は下端から）。つまみは「つまみ（ノブ）」の項の形にする。

| 項目 | 値 |
|---|---|
| 部品の矩形 | 44 × 202（描画幅 44 / クリック判定幅 28、中心 ±14） |
| 中心 x | 部品の左端 +22 |
| 名前（label） | 中心 y +7 |
| セル | 上端 y +22、**2 列 × 40 段** |
| 値（value） | 中心 y +194。値の入力欄は部品幅 × 14 px |
| つまみ | 値の段の 2 セルを `ink`（針は付けない） |
| 並べる間隔 | 中心間 36 px（詰める場合）／ 45 px（ゆったり） |
| ドラッグ量 | 全域 160 px、Shift のときは 0.2 倍 |

同じ行のフェーダーは、**部品の上端・名前・セルの上端・値の y をそろえる**。メーターを並べるときも同じ y にする。

### 横スライダー

セルを 1 段並べる。つまみは「つまみ（ノブ）」の項の形にする。名前は左、値は右。

| 項目 | 値 |
|---|---|
| 部品の矩形 | 228 × 14 |
| 名前 | x +4、縦中央 |
| セル | x +40 から **32 個 × 1 段** |
| 値 | 右端 x +224 に右寄せ。値の入力欄は右から 50 px |
| つまみ | 値のセルを `ink`（針は付けない） |
| 行ピッチ | 20 px |
| ドラッグ量 | 全域 128 px、Shift のときは 0.2 倍 |

### 四角トグル

| 項目 | 値 |
|---|---|
| 部品の矩形 | 18 × 16 |
| 四角 | 6 × 6、x +2、縦中央。オンは `accent` で塗り、オフは 1 デバイス px の枠（`ink3`） |
| 名前 | x +11（名前を付ける場合） |
| 並べる間隔 | 20 px |

### 文字トグル

文字そのものがボタン。オンは `accent`、ホバーは `ink`、オフは `ink3`。

| 項目 | 値 |
|---|---|
| 当たり判定 | 12 × 16（1 文字の場合） |
| 文字 | label 書体、判定の中央 |
| 並べる間隔 | 12 px |

### ピルボタン・セグメント選択

角丸の溝（`off`）。選択中のセグメントだけを `plot` で明るくし、細い `rule` の枠を付ける。文字は選択中が `ink`、ほかは `ink2`。

| 項目 | 値 |
|---|---|
| 高さ | **16 px**、角丸 = 高さの半分 |
| セグメントの幅 | 文字幅（label 書体、四捨五入）+ 16 px |
| 選択中のセグメント | 1 px 内側に `plot` 色のピル + 1 デバイス px の `rule` 枠 |

### アイコン

アイコンはドットで組まず、**線で描く普通のアイコン**にする。隣に並ぶ文字の 1 文字と同じ扱いにし、大きさも文字にそろえる。色はフッターの規則に従う（通常 `ink3`、ホバー `ink`）。

**大きさ**

| 項目 | 値 |
|---|---|
| 外形 | 隣の文字の書体サイズと同じ正方形（フッターなら note 書体の 7.5 × 7.5 px） |
| 線の太さ | 外形の 1/8（7.5 px なら約 0.94 px）。1 デバイス px より細くしない |
| 線の端・角 | 端は切りっぱなし（丸めない）、角はとがらせる |
| 縦位置 | 外形の中心を、隣の文字の中心線にそろえる（フッター上端 +11） |
| 当たり判定 | 幅 = 外形 + 6 px（13.5 px）、高さ 14 px。外形を判定の中央に置く |

**間隔**

| 項目 | 値 |
|---|---|
| アイコン同士 | 当たり判定をすき間なく並べる（外形同士のすき間 6 px） |
| アイコンと文字のボタンのグループの間 | 10 px 空ける |

**共通のアイコン**

| アイコン | 形 |
|---|---|
| Reset（↺） | 外形いっぱいの円の線。右上（時計の 1 時から 2 時の間）を開け、開いた右上の端に塗りつぶしの三角の矢じりを付ける |
| テーマ（◧） | 外形いっぱいの四角の線。左半分を塗りつぶす |

- 新しいアイコンを足すときも、同じ外形・線の太さで、線と塗りだけで描く。グラデーションや影は使わない。
- アイコンに限り、円の線を使ってよい（データの点は引き続き四角だけ）。

### 表示域（グラフ）

セルを敷き詰めて描く。データは `kept`、「効いている・変わった量」だけをオレンジにし、音として出ていない部分は `ghost` にする。基準線は黒の細線で、操作中だけ少し太くして、値を吹き出しで示す。

| 項目 | 値 |
|---|---|
| 表示域の端 | 10 の倍数にそろえる。セルは表示域の左上から敷き詰める |
| 中心線を持つ表示 | 段数を奇数にして、中心の段の上下を同じ段数にする |
| 横軸の目盛り | 表示域の下端から 12 px 下に中心、数字のみ（tick 書体、`ink2`） |
| 縦軸の目盛り | 表示域の右 7 px、数字のみ（tick 書体、`ink2`） |
| 表示域の上のラベル | 表示域の上端から 10 px 上 |
| 基準線・境界線 | 0.5、ホバー・ドラッグ中 1.2 |

### メーター

四角ドットを縦に並べる。基準以下は `kept`、超えた部分だけオレンジにする。

| 項目 | 値 |
|---|---|
| ドット | 表示域と同じセル、2 列 |
| 基準レベルの線 | ドット 2 列の幅ちょうど（7 px）、太さ 0.5 |
| 並べ方 | 隣のフェーダーや表示域と、上端・下端の y をそろえる |

### 信号経路の表示

小さな四角のノード（有効 = 塗り / 無効 = 枠）を細い線でつなぐ。

### ドット数字・ロゴ

消灯ドットも薄く描く。0 に斜めの点を入れない。ロゴは最後の 1 文字だけオレンジにする。

| 項目 | ドット | ピッチ | 1 文字 | 文字間 |
|---|---|---|---|---|
| ドット数字 | 1.6 px | 2 px | 5 × 7（高さ 13.6 px） | 1 列空ける |
| ロゴ | 3 px（セル） | 4 px | 4 × 5（高さ 19 px） | 1 列空ける。ロゴ区画の左上から (+10, +5.5) |

### 吹き出し

`ink` の地に `onInk` の文字（value 書体）。ホバーした位置の値を見せる。

| 項目 | 値 |
|---|---|
| 大きさ | 高さ 14、幅 = 文字幅 + 10、角丸 3 |
| 位置 | 対象の 12 – 14 px 上。表示域の左右にはみ出さない |

### ツールチップ

`tipBg` の地に、1 行目はオレンジの見出し（label 書体、大文字）、2 行目以降は日本語の短い説明（`tipText`、行間 1.55）。吹き出しを出す場所には付けない。

| 項目 | 値 |
|---|---|
| 余白 | 左右 9 / 上下 7、見出しと本文の間 4 |
| 最大幅 | 220 |
| 角丸 | 3 |
| 位置 | カーソルの右下（+14, +18）。画面の端では反対側に回し、見切れないようにする |
| 表示までの時間 | 0.5 秒 |

寸法はすべて UI スケールを掛ける。

### 入力欄

地は `plot`、1 デバイス px の `rule` の枠、value 書体で中央揃え。開いたら全選択する。

### 無効状態

点灯セル・つまみ・文字をそれぞれ `dLit`・`dKnob`・`dText` に置き換える。形は変えない。

## 8. 線の太さ

| 種類 | 値 |
|---|---|
| 罫線 | 0.2 px、`rule`（そのまま描く） |
| 基準線・境界線 | 0.5、操作中 1.0 – 1.2 |
| 枠線（トグル、選択セグメント、入力欄） | 1 デバイス px |

0.2 px の罫線以外は、**1 デバイスピクセル未満にしない**。位置もデバイスピクセルにそろえる。

## 9. 操作の手触り

| 操作 | 動作 |
|---|---|
| ドラッグ・ホイール | **決まった刻みで止まる** |
| Shift ＋ドラッグ／ホイール | 細かく動く（刻みを細かくし、ドラッグ量は 0.2 倍） |
| ダブルクリック（操作部） | 初期値に戻る |
| ダブルクリック（値の文字） | 直接入力。Enter で確定、Esc で取り消し、外をクリックしても確定 |
| Alt ＋クリック | 初期値に戻る（UI サイズのボタンは 100 %） |
| Ctrl+Z / Ctrl+Shift+Z・Ctrl+Y | 元に戻す／やり直す。1 回のドラッグやホイール操作を 1 ステップとする。ボタンは置かない |
| Reset のクリック | すべてのつまみなどを初期値に戻す。Ctrl+Z で元に戻せる |
| リサイズ角のドラッグ | 縦横比を保ったまま 75 〜 125 % の間で連続して変わる |
| テーマ切替のクリック | ライトとダークが入れ替わる。すべてのプラグインで共通の設定として保存する |

### テーマ設定の保存

テーマはプロジェクトごとではなく、**ユーザーごとに 1 つ**の設定として全プラグインで共有する。

| 項目 | 値 |
|---|---|
| ファイル | `<設定フォルダ>/PC1-style/settings.cfg` |
| 設定フォルダ | Windows は `%APPDATA%`、macOS は `~/Library/Application Support`、Linux は `$XDG_CONFIG_HOME`（なければ `~/.config`） |
| 書式 | 1 行に `キー = 値`。テーマは `theme = light` または `theme = dark`。ファイルがない、または読めないときはライト |
| 書き込み | 切り替えたときに `theme` の行だけを書き換え、ほかの行は残す（ほかのプラグインが使うキーを消さない） |
| 読み込み | エディターを開いたとき。開いている間も 1 秒ごとにファイルの更新時刻を見て、ほかのプラグインで切り替えられたら追従する |
| カーソル | 縦に動く値は上下矢印、横は左右矢印、ボタンは指、リサイズ角は斜め矢印 |

## 10. チェックリスト

**見た目**
- [ ] 背景は `cell` の 1 色だけか
- [ ] 色はすべてトークン経由で、ライトとダークの両方で確認したか
- [ ] Reset とテーマ切替はフッターにあり、並びは共通どおりか。Undo・Redo のボタンを置いていないか
- [ ] 丸い点・影・グラデーション・目盛り線が残っていないか
- [ ] オレンジは「効いている・変わった・オン・基準超え」とロゴの最後の 1 文字だけか
- [ ] 文字の色は `ink`・`ink2`・`ink3` だけか（無効状態の `dText` は除く）
- [ ] フォントは Chivo Mono で、サイズは 4 段（8 / 9 / 7.5 / 7.5）に収まっているか
- [ ] つまみは「値の位置の黒いセル」だけで、針や線が付いていないか。どの部品でも同じ形か
- [ ] つまみはセル単位で動き、ホバーやドラッグで形が変わらないか
- [ ] アイコンはドットではなく線で描かれ、隣の文字と同じ大きさ・同じ中心線か
- [ ] ツールチップが見切れず、吹き出しと重なっていないか

**寸法**
- [ ] ベースサイズは 10 の倍数で、縦横比は固定か
- [ ] スケールは 75 / 100 / 125 % のボタンとドラッグ（0.75 – 1.25）で、初期は 1.0 か
- [ ] 100 % の窓が FHD・Windows 125 % の画面に収まるか
- [ ] 外側の余白は 20 px、フッターは 40 px（左にバージョン、右に UI サイズのボタン）か
- [ ] サイド列を作るなら 120 px 幅か
- [ ] 区画の見出しは区画の左上から (+10, +15)、番号と名前の間は 14 px か
- [ ] セルは 3 px / 4 px ピッチで、デバイスピクセルにそろっているか。どのサイズでもすき間がつぶれていないか
- [ ] 罫線は 0.2 px、基準線は 1 デバイス px 以上か
- [ ] 縦フェーダーは 44 × 202・40 段、横スライダーは 228 × 14・32 セル・行ピッチ 20 か
- [ ] ピル・ボタン類の高さは 16 px、四角トグルは 6 px か
- [ ] 同じ行のフェーダー・メーターは、名前・セルの上端・値の y がそろっているか
